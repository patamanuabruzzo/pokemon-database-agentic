# Start your applications

## Instructions

- Run the commands in the `Run` section below
- Frontend runs on port 3000 (Vite dev server with hot reload)
- Backend runs on port 3001 (Express API)
- Choose which service to start based on your needs
- For development, run frontend and backend in separate terminals

## Run

# Start frontend (React + Vite)
npm run dev:client

# Start backend (Express API) - run in separate terminal
npm run dev:server

# Or start both in one command (requires bash)
npm run dev:client & npm run dev:server
